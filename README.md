# Sofix Lab

Professional graphic design portfolio for Sohag Hossain, built with React, Vite, TypeScript, and Tailwind CSS.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The production output is generated in `dist/`. Vercel automatically detects the Vite configuration; no additional settings are required.
